# الشات الخاص وجروبات الحصص — إصدار 1.6

## الصلاحيات

| الدور | بدء المحادثة | جروبات الحصص |
| --- | --- | --- |
| المدرس | الطالب وولي أمره في مجموعاته النشطة | إنشاء جروب لحصته وتعديل الاسم والسماح بردود الطلبة أو الإعلانات فقط وإغلاقه وإعادة فتحه |
| الطالب | مدرسه عبر تسجيل نشط | قراءة ومشاركة حسب إعداد المدرس |
| ولي الأمر | مدرس الابن المرتبط به عبر تسجيل نشط | لا يدخل جروب الطلاب؛ محادثته الخاصة منفصلة عن الطالب والأولياء الآخرين |

تُراجع عضوية المجموعة الحالية وحالة الطالب وموافقة ولي الأمر وحالة المدرس عند عرض الأشخاص وقراءة المحادثات والإرسال والتحديث اللحظي. إلغاء التسجيل أو إيقاف المجموعة يسحب الوصول. تظل المحادثة الخاصة مسموحة إذا كان هناك تسجيل نشط آخر مع نفس المدرس. الطلاب الجدد المسجلون في المجموعة يستطيعون قراءة تاريخ جروب الحصة الموجود. الصلاحيات لا تعتمد على قائمة مشاركين قديمة محفوظة.

## API

كل المسارات تحت `/api/v1` وتتطلب جلسة السنتر وميزة messaging وصلاحيات الرسائل المناسبة.

| المسار | الاستخدام |
| --- | --- |
| GET `/chat/contacts` | الأشخاص المؤهلون؛ studentId وgroupId وcontactRole وsearch وpage وpageSize |
| GET `/chat/conversations` | صندوق المحادثات؛ studentId وkind وصفحات |
| POST `/chat/direct` | studentId وteacherId وguardianId الاختياري؛ يعيد المحادثة الموجودة إن وجدت |
| GET `/chat/session-options` | حصص المدرس المؤهلة ومعرّف جروبها إن وجد |
| POST `/chat/session-groups` | sessionId وtitle الاختياري وallowStudentMessages؛ يعيد الموجود دون تغيير إعداداته |
| GET `/chat/conversations/{id}` | التفاصيل الحالية وcanSend وcanManage |
| GET `/chat/conversations/{id}/messages` | الأحدث أو beforeId للأقدم أو afterId للأحدث؛ لا يجمع المؤشرين؛ pageSize حتى 50 |
| POST `/chat/conversations/{id}/messages` | body حتى 2000 حرف وclientMessageId بصيغة UUID |
| PUT `/chat/conversations/{id}/settings` | title وallowStudentMessages وstatus بقيمة Open أو Closed؛ لمدرس المجموعة فقط |

الرسالة المكررة بنفس المفتاح والمحتوى تعيد الرسالة السابقة؛ اختلاف المحتوى بنفس المفتاح يعيد 409. هوية المرسل واسمه ودوره من الخادم. رسائل التاريخ مرتبة زمنيًا بمعرّف خادم متزايد. NextBeforeId للأقدم وNextAfterId لاستكمال دفعات التحديثات الجديدة.

SignalR يرسل `ChatChanged` بمعرفات فقط للمشاركين المسموح لهم حاليًا. يجلب الموبايل النص عبر REST المحمي، مع مزامنة احتياطية كل خمس ثوان بالمقدمة. لا توجد مرفقات أو صوت أو read receipts أو Push خلفية في هذا الإصدار. المحادثات القديمة تبقى متاحة بمساراتها بعد تشديد الخصوصية ولا يُرحّل سجلها تلقائيًا.

## النشر

1. انشر الباك إند مع تطبيق migration `20261029120425_ScopedChat` بالطريقة المعتادة في بيئة النشر. تضيف ChatConversation وChatMessage وفهارسها، دون حذف الجداول القديمة.
2. تأكد من ميزة messaging وصلاحيات messages.view/create/update ومن تسجيل الطلاب والمجموعات الفعّال.
3. انشر تطبيق الموبايل `1.6.0+8` بعد الباك إند.

تم تجميع API والاختبارات محليًا. تم تشغيل 9 اختبارات بعزل SQLite وTestServer: نطاق الأشخاص والخصوصية والبدء من الطرفين والعضوية والإعلانات والإغلاق ومنع التكرار والمؤشرات وعزل السنترات والأدوار وتلميحات التحديث اللحظي واختبار اختيار المدرس السابق. تم التحقق من تطابق snapshot مع الموديل وتوليد SQL إضافي. هذه اختبارات ببيانات مصطنعة؛ لا تعني تطبيق migration على الإنتاج أو تجربة OTP حي.
